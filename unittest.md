## CI/CD

Continuous integration
    - frequent merges to main branch
        - prevent large merges with potential conflicts
    - automated unit testing
        - a series of unit tests allows small components to be verified working even with new changes
Continuous delivery
    - short release schedules
        - releases should not take longer to debug and merge than to write the code fore

- These ideas prevent big changes from being merged into the branches so that small increments can be merged
at a time with less conflicts and errors.
